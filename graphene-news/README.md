# Graphene News Aggregation System

## Overview
Automated news aggregation system for graphene industry content, featuring AI-powered content processing, legal compliance, and seamless integration with the main production tracking app.

## Architecture
- **Backend**: Content acquisition, processing, and API services
- **Frontend**: Modern card-based news feed UI components  
- **Config**: Source management and categorization settings
- **Legal**: Compliance framework for web scraping and content usage

## Features
- Automated RSS feed aggregation
- AI-powered content relevance scoring
- Visual content extraction with image caching
- Real-time updates and notifications
- Advanced search and filtering
- Export functionality for research documentation

## Integration
Integrates seamlessly with existing Express/Alpine.js/Prisma architecture via:
- New "News Feed" tab in navigation
- Dashboard widget for latest headlines
- Shared database and authentication system
