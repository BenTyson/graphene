# Railway Deployment Guide

## Database Migration Strategy

### PostgreSQL Setup on Railway

1. **Create PostgreSQL service** in your Railway project
2. **Copy connection string** from Railway PostgreSQL service
3. **Set DATABASE_URL** environment variable in Railway

### Migration Process

```bash
# Railway will automatically run these commands during deployment:
npx prisma generate
npx prisma db push
```

### Production Database Considerations

- **Backup Strategy**: Railway provides automatic backups
- **Connection Pooling**: PostgreSQL connection limits handled by Railway
- **Migrations**: Use `prisma db push` for schema changes (no migration files needed)

### Data Seeding (Optional)

If you need initial data:
```bash
# Add to package.json scripts:
"seed": "node prisma/seed.js"
```

### Environment Variables Required

Set these in Railway dashboard:

```
DATABASE_URL=<auto-generated-by-railway>
OPENAI_API_KEY=<your-openai-key>
JWT_SECRET=<secure-random-string>
NODE_ENV=production
PORT=3000
MAX_FILE_SIZE=10485760
ALLOWED_FILE_TYPES=pdf,doc,docx,txt
```

### Branch Strategy

- **main branch** → Production deployment at admin.hgraphene.com
- **develop branch** → Staging deployment at <app-name>-staging.up.railway.app

### Custom Domain Setup

1. Add custom domain in Railway project settings
2. Point DNS CNAME record: `admin.hgraphene.com` → `<your-app>.up.railway.app`
3. Railway handles SSL certificates automatically
